# 🧮 Calculadora Tkinter

Uma calculadora simples desenvolvida em **Python** com **Tkinter**, biblioteca utilizada para criar interfaces gráficas.

Este projeto foi criado para praticar os fundamentos de Python e o desenvolvimento de aplicações com interface gráfica.

## 🚀 Funcionalidades

- Visor para exibir expressões matemáticas e resultados
- Botões numéricos de 0 a 9
- Operações básicas: adição (`+`), subtração (`-`), multiplicação (`*`) e divisão (`/`)
- Botão `=` para calcular o resultado
- Botão `C` para limpar o visor
- Interface gráfica com botões e campo de entrada

## 🛠️ Tecnologias utilizadas

- Python
- Tkinter

## 📋 Pré-requisitos

- Python instalado
- Tkinter disponível na instalação do Python

### Instalação do Tkinter no Linux

Em distribuições baseadas no Ubuntu ou Debian, pode ser necessário instalar o pacote do Tkinter separadamente:

```bash
sudo apt update
sudo apt install python3-tk
```

Para verificar se o Tkinter está funcionando, execute:

```bash
python3 -m tkinter
```

Se estiver instalado corretamente, uma janela de teste será exibida.

## 📦 Como executar

1. Clone este repositório:

   ```bash
   git clone URL_DO_SEU_REPOSITORIO
   ```

2. Entre na pasta do projeto:

   ```bash
   cd calculadora-tkinter
   ```

3. Execute a calculadora:

   ```bash
   python3 calculadora.py
   ```

**Observação:** substitua `URL_DO_SEU_REPOSITORIO` pelo endereço HTTPS real do seu repositório no GitHub.
